# 🧁 Las chucherías de Becca - Aplicación Web

Sitio web oficial y catálogo interactivo con checkout directo a WhatsApp para **Las chucherías de Becca** (@laschucheriasdebecca), repostería artesanal en Toluca y Metepec, Estado de México.

---

## 🚀 Características Principales

1. **Catálogo Interactivo con Carrito de Compras:**
   - Postres frescos organizados por categorías: *Fresas, Uvas & Manzanas*, *Pasteles & Bento Cakes*, *Cupcakes*, *Galletas & Brownies*, y *Cajas de Regalo*.
   - Selector de opciones (coberturas, rellenos, tamaños) y notas/dedicatorias personalizadas.
   - Carrito desplegable con selector de método de entrega:
     - 🚗 **Envío a Domicilio** (Toluca, Metepec, Lerma, Zinacantepec).
     - 🏪 **Retiro en Taller** (El Oro 112, Toluca).
     - Selector de fecha deseada y horario preferido.
   - **Botón de checkout a WhatsApp (+52 722 562 8061):** Formatea el pedido completo con subtotal, productos y dirección, listo para enviar con 1 clic y con efecto festivo de confetti.

2. **🎂 Cotizador Interactivo de Pasteles para Eventos:**
   - Wizard paso a paso para eventos (cumpleaños, bodas, infantiles, baby shower).
   - Elección de porciones (desde Bento Cake hasta pasteles de 2 pisos).
   - Selección de sabores de bizcocho, rellenos gourmet y coberturas.
   - Envío de cotización estructurada directo a WhatsApp con aviso de fotos de referencia.

3. **📱 Conexión Directa con Instagram:**
   - Enlace directo al perfil `@laschucheriasdebecca` con más de 1,500 seguidores.
   - Galería visual estilo feed de Instagram con likes y comentarios.

4. **👩‍🍳 Sección "Conoce a Becca":**
   - Historia de Rebecca Sánchez, valores de la marca e ingredientes 100% artesanales.

5. **❓ Preguntas Frecuentes (FAQ):**
   - Políticas de anticipo del 50%, tiempos de anticipación y zonas de cobertura.

6. **🛠️ Panel de Gestión Rápida (Administración sin código):**
   - Ubicado discretamente en el pie de página (botón *Gestión*).
   - Permite a Becca o a ti:
     - Cambiar precios al instante.
     - Agregar nuevos productos con su foto, descripción y precio.
     - Modificar el número de WhatsApp receptor o el texto del banner de anuncios.
     - Los cambios se guardan localmente en el navegador.

## 💻 Comandos Rápidos

```bash
# Iniciar en modo desarrollo

# Generar versión optimizada para producción
npm run build

# Previsualizar la versión de producción
npm run preview
```

## 🌐 ¿Cómo subirla a Internet Gratis?

Puedes publicarla en menos de 3 minutos de forma 100% gratuita y con certificado SSL (candado verde HTTPS) en:

1. **Vercel** o **Netlify**:
   - Conecta tu cuenta de GitHub con esta carpeta y haz clic en *Deploy*.
   - ¡Listo! Tendrás un enlace como `laschucheriasdebecca.vercel.app` o podrás conectarle un dominio propio como `laschucheriasdebecca.com`.
